# Third-party code

The Relapse runtime files in this repository are derived from
[vinasxexplosao/relapsenadarepublicano](https://github.com/vinasxexplosao/relapsenadarepublicano),
upstream revision `178e4cf02ca463f5a229aaeb0a5d63f8d265041e`. The files are attributed in the
launcher UI and retained with their original author notices where present.

The package build uses [LibProsperoPKG](https://github.com/SvenGDK/LibProsperoPKG), pinned to
`748eabf1b7d17819528cabf367d8e27109d8fce3`; it is fetched by the workflow and is not vendored here.
